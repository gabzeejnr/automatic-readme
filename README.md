
# Website Readme Generator

This project is used to generate README.md files for websites using the url, title, description, heading tags, links and image tags available in the website.
## Acknowledgements

 - [Gabriel Dodowei - Script writer](https://gabrieldodowei.vercel.app)
 - [ChatGPT - Project Planner](https://chatgpt.com)


## Deployment

To deploy this project, clone the repository and then run

```bash
  npm run build 
```

```bash
  npm run dev -- <webpage-url> <path-to-project-on-computer>
```

```bash
  npm run start
```
